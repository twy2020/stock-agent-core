# Core 配置管理改版

## 管理界面

- 管理端使用账号密码登录，默认账号 `admin`、初始密码 `admin123`。首次登录仅允许改密及退出，修改后才能进入控制台。密码保存在 Core SQLite 中，不写入供应商配置；旧管理员令牌不再接受。
- 侧栏可修改密码。新密码要求 10–128 个字符，改密使其他会话失效；登录会话最长八小时，五分钟内五次失败后暂时限制登录。

- 供应商使用紧凑树形列表：供应商 → 账号 → API Key → 模型。独立模型仍可编辑，不要求迁移配置。
- 支持树节点展开收起、全部展开收起、跨层级搜索和方向键导航。
- 点击名称或编辑图标打开右侧抽屉；手机使用全宽抽屉。编辑区可独立滚动，保存栏固定。
- 名称、ID、Base URL、API 类型、API Key、Model ID 等常用字段直接显示。
- API Key 可直接输入并查看本次输入；保存后不回显。更换共享 API Key 时提示模型引用范围。
- 新增供应商可同时填写 API Key，后台自动创建默认账号和凭据，无需先创建三层记录。
- 模型支持供应商 API Key 和独立接口两种连接方式；MCP / HTTP 工具直接输入 Bearer Token。

## 保存行为

`POST /admin/api/connections` 接收版本号、配置类型、ID、变更字段及 API Key。使用现有管理员鉴权、版本校验、活动任务锁、候选配置校验和配置原子替换流程。

供应商、账号、密钥联合变更只写入一次配置，同时更新内存中的相关集合并保留已有对象身份。凭据保存至服务端专用文件，返回数据仅包含配置状态，不返回凭据内容或文件路径。

通用 registry 接口继续兼容原配置引用。更新凭据不改变应用授权或当前默认模型。

## 验证

管理 API 测试覆盖一表单创建供应商及密钥、轮换共享密钥、切换独立模型连接、工具 Token、跨供应商引用拒绝、无效配置不产生部分更新。

`scripts/preview_core_admin.py` 提供隔离预览。预览不读取正式配置或凭据，不连接正式模型接口。

浏览器验证脚本：`rag-chat-saas/frontend/scripts/verify-core-provider-tree.mjs`，覆盖桌面 / 手机、明暗主题、树搜索、抽屉保存、旧模型凭据编辑及敏感字段不回显。
